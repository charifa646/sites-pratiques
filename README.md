# sites-pratiques

Espace de travail regroupant plusieurs projets de sites (projets fictifs /
de démonstration). Chaque projet vit dans son propre sous-dossier.

## Projets

| Dossier                        | Description                  | Stack                                                   |
| ------------------------------ | ---------------------------- | ------------------------------------------------------- |
| [`kora-transit/`](./kora-transit) | Premier projet (en cours) | Next.js 14 · TypeScript · Tailwind CSS v3 · Framer Motion 11 |

## Démarrer un projet

```bash
cd kora-transit
npm install
npm run dev
```

Voir le README de chaque projet pour le détail.
